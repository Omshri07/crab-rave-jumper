## Title
```
Crab Rave: a Jumper crab robot dances. Trained on a laptop CPU, no GPU
```
(70 characters. For a Short, append ` #Shorts`.)

## Description
```
KingKong's open-source Jumper crab robot dancing in a neon Crab Rave disco, all in simulation.

I trained the dance on a Ryzen 5 laptop CPU with no GPU: 2 hours 31 minutes, 256 simulated robots, 1,500 iterations. Then I built the disco floor and gave the robot a black, white and violet striped suit.

What is mine: the Crab Rave scene, the striped skin, the training run and the filming. The dance itself is the demo choreography that ships with the open-source toolkit.

Toolkit: https://github.com/KingKongRobotics/jumper
Challenge: https://beunlimited.me/en/events/crab-robot-challenge-2026
My entry for the Crab Robot Open-source Challenge by @KingKongRobotics

No music was added, so the video is silent.

#Jumper #CrabRobot #OpenSourceRobot
```
Replace `@KingKongRobotics` with the official channel handle (type `@KingKong` in the
description box and pick the official channel from the suggestions).
YouTube shows the first three hashtags above the title, so the three required tags go last
in the description and still appear.
